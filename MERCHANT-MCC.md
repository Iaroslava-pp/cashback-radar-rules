# MCC торговых точек

`merchant-mcc.json` — отдельный справочник торговых записей. Он не содержит MCC категорий банков, банковских условий, карт или исправлений пользователей.

Начальная версия повторяет 15 встроенных справочных записей приложения. Это типовые MCC торговых сетей, а не подтверждённые MCC каждого магазина или терминала: конкретная операция может иметь другой код. Уточнённые записи конкретных точек должны получать собственный постоянный ID; ID сети нельзя переиспользовать для отдельного терминала.

При публикации повышаются общая `version` и `version` изменённых записей. Смена MCC без новой версии записи запрещена клиентом. Клиент хранит пользовательский код отдельно на устройстве. Если новый исходный MCC точки изменился и расходится с пользовательским, требуется решение сохранить свой / принять новый / отложить. Банковский OCR и обновления банковских правил в этом механизме не участвуют.

JSON загружается по HTTPS без передачи пользовательских данных. Поддерживается проверка версий и атомарное сохранение; автоматического сбора MCC реальных терминалов нет.
