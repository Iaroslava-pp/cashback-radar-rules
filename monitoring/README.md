# Наблюдение за официальными документами

Эти файлы предназначены для публичного cashback-radar-rules: workflow — в `.github/workflows/bank-documents.yml`, источники — в `monitoring/sources.json`, инструменты и тест — в `tools/`.

Проверка запускается каждые четыре часа. С 24-го по 2-е число по Москве каждый запуск проверяет источники; в остальные дни скачивание выполняется раз в сутки. После ошибки источник остаётся просроченным и повторяется при следующем запуске. Никакие сведения пользователя не передаются.

`monitoring/observations.json` содержит только SHA-256, моменты успешных проверок и историю обнаруженных документов. PDF/HTML, извлечённый текст и отчёт сохраняются как артефакт на 90 дней. 403, таймаут и ошибка извлечения остаются ошибкой задания. Они не считаются отсутствием изменений. ВТБ временно выключен по прямому указанию владельца отложить его сверку на конец.

Изменение документа получает `review_required`; даже совпадающий текст при изменении бинарного файла остаётся видимым. Наблюдение **не меняет** `mcc-rules.json`, дельты, MCC торговых точек и даты начала действия. Дата обнаружения не является датой вступления в силу. Для публикации необходимо сверить таблицы и все условия, задать даты редакции, подготовить совместимую проверенную дельту и её SHA-256. Автоматическое извлечение условий и обнаружение новых ссылок PDF на страницах остаются следующей частью конвейера.
